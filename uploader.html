DDOGTAVI Uploader

A private desktop tool that publishes Daily Dose of GTA VI's own finished videos to the channel's own accounts.

Who uses it

Only the owner of the Daily Dose of GTA VI channels. The tool runs on the owner's own computer. There is no public sign-up and no other user accounts, and no data from viewers or other platform users is collected.

How it works

  1. Sign in once. The owner connects their own account with the platform's official login: Google OAuth for YouTube, Login Kit for TikTok (started on this site, which returns to tiktok/callback.html) and Meta login for Instagram.
  2. Check the account. The posting page (gabriel-ags.github.io/ddogtavi/tiktok/) shows the connected account's display name and avatar (TikTok user.info.basic), so the owner always sees which account will post.
  3. Review the video. The owner picks a finished video, sees a preview and edits the caption.
  4. Choose the settings. Privacy level (no default; only the options TikTok returns for the account), comments, Duet and Stitch on or off, and commercial content disclosure. The owner must accept TikTok's Music Usage Confirmation.
  5. Post. After the owner clicks Post, the tool uploads the video (TikTok Content Posting API, video.publish) and shows the publish status until the post is live.

Expected volume: 1 to 3 posts per day across the channel's accounts.

Data and permissions

  • Access tokens are stored only on the owner's computer and are used only to post the owner's own videos.
  • No platform data is shared, sold or shown to anyone else.
  • Access can be revoked at any time in the platform's settings (TikTok: Settings → Security → Manage app permissions).
