Privacy Policy

Daily Dose of GTA VI Uploader · Last updated: November 3, 2026

Daily Dose of GTA VI Uploader ("the tool") is an internal tool operated by the owner of the "Daily Dose of GTA VI" channels. It is used exclusively to upload videos produced by the channel owner to the channel owner's own YouTube, TikTok and Instagram accounts.

Data we access

The tool uses the OAuth access token of the channel owner's own account only to upload videos and set their title, description, privacy setting and publish time. It does not read, store or process data of any other platform users.

YouTube API Services

The tool uses YouTube API Services (scope youtube.upload) to upload videos to the channel owner's own YouTube channel. By using the tool you agree to be bound by the YouTube Terms of Service. Data accessed through YouTube API Services is handled in accordance with the Google Privacy Policy. No YouTube API data (such as channel or video information) is stored, shared with third parties or shown to anyone else; only the OAuth refresh token is kept locally so the owner does not need to sign in every time. Access can be revoked at any time via the Google security settings page, after which the stored token stops working and is deleted.

TikTok

For TikTok the tool uses Login Kit and the Content Posting API (scopes user.info.basic, video.publish) to show the connected account's display name and avatar and to publish the owner's videos. Access can be revoked at any time in the TikTok app under Settings → Security → Manage app permissions.

Cookies

This website and the tool do not use cookies or tracking technologies.

Community clip submissions

Viewers can voluntarily submit clips through a form (Tally). A submission contains the clip, a credit name, an optional profile link and a contact email. Submitters explicitly consent to their clip being published with credit. Contact emails are used only to reach the submitter about their clip and are never published, sold or shared.

Automated review

Submitted clips are checked for policy compliance (for example sexual, hateful or violent real-world content) with automated tools before publication. Clips that do not pass are not published.

Storage and deletion

Access tokens and submissions are stored locally on the channel owner's computer. Tokens can be revoked at any time in the respective platform's account settings. Submission data is deleted on request.
